# SAKINA | سَكِينَة

Arabic and English Islamic life organizer for Android: prayer times, adhkar, Quran with tafsir, tasks, study and habits. Free, no ads, works offline, no accounts.

- Website and download: https://skina.web.app
- Releases (APK): https://github.com/Kaiox1290/sakina-app/releases
- Developed by Yousef Esam

## Build

Android Studio or Gradle 8.7, JDK 17. `gradle assembleDebug`. Release signing uses environment variables and a private key that is not in this repository, so your build will have a different signature from the official APK.
